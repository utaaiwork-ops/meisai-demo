# 送金明細 送信システム — 商談用デモ

不動産管理会社の「毎月の送金明細書メール送付業務」を自動化する業務ツールの **デモ環境** です。

**▶ デモを開く: https://utaaiwork-ops.github.io/meisai-demo/**

---

## このデモについて

- 画面に出てくる会社名・担当者名・オーナー名・物件名・メールアドレス・金額・PDFは **すべて架空のサンプル** です。実在の個人・法人とは一切関係ありません。
- バックエンドを持たない静的なデモです。**実際のメール送信・ファイル保存は一切行われません。**
- 添付ファイル名をクリックすると、サンプルの送金明細書PDFが開きます。

## 何をするツールか

スキャンした送金明細PDFを起点に、月次のメール送付業務をワンクリックまで縮めます。

| 工程 | ツールの役割 |
| --- | --- |
| PDF読み取り | 貸主名・物件名・対象月・金額を抽出 |
| 名簿照合 | 宛先・CC・書類上の名称・清掃報告書の要否を突き合わせ |
| 送信前チェック | `OK` / `要確認` / `送信不可` / `NAS保管のみ` を自動判定 |
| メール作成 | 件名・本文・添付を自動生成 |
| 送信 | 人が最終確認してからボタンで実行 |
| 保管 | 送信後のPDFを物件別フォルダへ自動保存 |

## 安全設計（AIが勝手に送らない）

- AIの役割は「読み取り・照合・警告出し」まで。**最終送信は必ず人がボタンを押す**
- `送信不可` の明細は自動で除外。1件の問題で全件が止まらない
- `要確認` は理由を画面で確認してから送信
- テスト送信モードでは本番宛先に送らず、確認用アドレスへ上書き
- 同じPDFの二重送信をブロック
- メールアドレス未登録の貸主は送信せず、NAS保管のみ

## 技術構成

- フロントエンド: Next.js 15 / React 19 / TypeScript / Tailwind CSS 4
- バックエンド（本番構成）: FastAPI / Python、PDF OCR、Outlook連携、NAS保管
- 本デモ: 上記フロントエンドを静的書き出し（`next build` + `output: "export"`）し、モックデータで動作させたもの

本番システムのソースコードは非公開リポジトリで管理しています。
